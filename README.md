## 矩阵专题总结

本次新增的四道题形成了一个比较完整的矩阵入门模块。

### 48. 旋转图像：坐标映射

顺时针旋转 $90^\circ$ 时，原位置与新位置的关系是：

$$
(i,j) \rightarrow (j,n-1-i)
$$

如果一边读取原矩阵、一边写回原矩阵，尚未读取的值可能被提前覆盖。因此可以先复制原矩阵，再按照坐标关系写回。

不过这道题要求严格原地旋转，最终还需要掌握：

1. 沿主对角线转置矩阵；
2. 反转每一行。

这样可以把额外空间降到 $O(1)$。

### 54. 螺旋矩阵：维护四条边界

使用四个变量表示尚未访问的矩形范围：

```python
top = 0
bottom = m - 1
left = 0
right = n - 1
```

每遍历完一条边，就把对应边界向内移动：

- 上边：从左到右，随后 `top += 1`；
- 右边：从上到下，随后 `right -= 1`；
- 下边：从右到左，随后 `bottom -= 1`；
- 左边：从下到上，随后 `left += 1`。

矩阵可能只有一行或一列，因此每走完一条边都要及时判断元素是否已经全部加入结果。

### 73. 矩阵置零：先记录，后修改

不能在第一次扫描到零时立刻把整行、整列清零，否则新写入的零会被误认为原始零，继续影响其他位置。

当前实现分成两个阶段：

1. 使用两个集合记录原始零所在的行和列；
2. 再次遍历矩阵，根据记录统一置零。

这种写法会直接修改输入矩阵，因此属于原地修改；但仍使用了 $O(m+n)$ 的辅助空间。若要进一步优化到 $O(1)$，可以使用第一行和第一列充当标记数组。

### 240. 搜索二维矩阵 II：利用有序性

当前实现利用了“每一行从左到右递增”的条件：

```python
if matrix[i][j] > target:
    break
```

当某个元素已经大于目标值时，该元素右边的值只会更大，因此可以结束当前行的搜索。

当前实现还没有利用“每一列从上到下递增”的条件，最坏时间复杂度仍为 $O(mn)$。后续可以从右上角开始：

- 当前值大于目标值：向左移动；
- 当前值小于目标值：向下移动；
- 每次排除一整行或一整列，将复杂度优化为 $O(m+n)$。

## Python 二维列表复制

### 错误写法：所有行指向同一个列表

```python
matrix_copy = [[0] * n] * n
```

外层的 `* n` 复制的是同一个内部列表的引用，而不是创建 $n$ 个相互独立的列表。因此：

```python
matrix_copy[0][0] = 1
```

会导致每一行的第一个元素一起改变。

### 正确创建独立的二维列表

```python
matrix_copy = [[0] * n for _ in range(n)]
```

列表推导式每次循环都会创建一个新的内部列表，所以各行互不影响。

### 复制已有二维列表

```python
matrix_copy = [row[:] for row in matrix]
```

这里的 `row[:]` 会为每一行创建一个新列表。对于元素都是整数的二维列表，这样已经能够得到相互独立的副本。

下面的写法只复制了外层列表：

```python
matrix_copy = matrix[:]
```

两个矩阵内部仍然引用相同的行，修改某个元素时仍会互相影响。

## Python 常用语法

### `range()` 反向遍历

```python
for i in range(10, 1, -1):
    print(i)
```

输出范围是 10 到 2，不包含结束值 1。`range(start, stop, step)` 的 `stop` 始终不包含在结果中。

在螺旋矩阵中，从 `right` 遍历到 `left` 需要写成：

```python
for j in range(right, left - 1, -1):
    ...
```

### 列表切片与拼接

```python
left_part = nums[:-k]
right_part = nums[-k:]
new_nums = right_part + left_part
nums[:] = new_nums
```

- 切片会复制指定范围内的元素；
- 列表的 `+` 表示拼接，并返回一个新列表；
- `nums = new_nums` 只是让局部变量指向新列表；
- `nums[:] = new_nums` 会替换原列表中的元素。

一次长度为 $n$ 的切片或拼接需要 $O(n)$ 时间和 $O(n)$ 空间。代码行数少不代表复杂度就是 $O(1)$。

### 字典成员判断与 `get()`

```python
if key in dictionary:
    ...

dictionary[key] = dictionary.get(key, 0) + 1
```

- `key in dictionary` 默认判断键是否存在；
- `get(key, 0)` 表示键不存在时返回默认值 0。

对应题目：1、49、76、560。

### `deque`：双端队列

```python
from collections import deque

queue = deque()
queue.append(value)
queue.pop()
queue.popleft()
```

列表的 `pop(0)` 会使后面的元素整体移动，时间复杂度为 $O(n)$；`deque.popleft()` 可以在 $O(1)$ 时间内从左侧删除。

对应题目：239。

### `lambda`：定义排序依据

```python
intervals.sort(key=lambda interval: interval[0])
```

这里的 `lambda interval: interval[0]` 表示：对每个区间取左端点作为排序依据。

对应题目：56。

## 从暴力解法到优化解法

| 暴力方法中的重复工作 | 优化方式 | 对应题目 |
| --- | --- | --- |
| 对每个元素再次遍历寻找搭档 | 用哈希表直接查找补数 | 1 |
| 枚举所有左右边界组合 | 根据短板性质排除一侧 | 11 |
| 三重循环寻找三元组 | 排序后固定一项，剩余两项使用双指针 | 15 |
| 对每根柱子重复寻找两侧最高值 | 移动中维护 `left_max` 和 `right_max` | 42 |
| 旋转时直接覆盖尚未读取的元素 | 使用正确的二维列表复制，或转置后逐行反转 | 48 |
| 反复计算每一圈的位置 | 使用 `top`、`bottom`、`left`、`right` 维护剩余范围 | 54 |
| 枚举所有连续子数组并分别求和 | 复用“以当前位置结尾”的最优状态 | 53 |
| 发现零后立即修改，导致零继续传播 | 先记录原始零所在的行和列，再统一修改 | 73 |
| 枚举所有起点并重新统计字符 | 在窗口边界移动时增量更新频次 | 76 |
| 重复进行 $k$ 次整体搬移 | 使用一次切片拼接或三次反转 | 189 |
| 为每个位置重新计算其余元素乘积 | 分别复用前缀积与后缀积 | 238 |
| 每个窗口重新扫描寻找最大值 | 用单调队列保留可能成为最大值的下标 | 239 |
| 扫描有序矩阵的每个元素 | 利用右上角的大小关系逐行或逐列排除 | 240 |
| 删除元素后整体移动列表 | 用快慢指针覆盖有效区域 | 283 |

共同思路是：

> 先找出暴力解法中的重复计算，再思考能否用已有状态、单调关系、移动边界或哈希结构保存它。

## 当前需要注意的问题

### 48. 旋转图像

当前文件中使用了：

```python
origin_matrix = [[0] * len(matrix)] * len(matrix)
```

这些行仍然指向同一个列表。即使后面逐个元素复制，也无法消除共享引用，因此当前代码会得到错误结果。

至少应改为：

```python
origin_matrix = [row[:] for row in matrix]
```

如果严格满足题目的原地要求，则应使用“转置矩阵 + 反转每一行”，将额外空间降为 $O(1)$。

### 240. 搜索二维矩阵 II

当前代码能够得到正确结果，并利用行有序性提前结束当前行，但没有利用列有序性。后续可尝试右上角搜索，把最坏时间复杂度从 $O(mn)$ 优化为 $O(m+n)$。
