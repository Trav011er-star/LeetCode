## 一、哈希表与集合：把“查找”变成状态记录

哈希结构适合解决两类问题：

- 快速判断某个对象是否已经出现；
- 保存一个对象到下标、数量或一组元素的映射关系。

平均情况下，字典和集合的查找、插入与删除都是 $O(1)$。

### 1. 字典：保存“键 → 信息”

```python
data = {}
data[key] = value

if key in data:
    value = data[key]
```

对字典使用 `in` 时，判断的是键是否存在。

### 2. 补数查找

遍历到一个数字时，不再重新遍历数组寻找搭档，而是直接计算当前需要的数字：

```python
need = target - num
```

字典保存：

```text
已经遍历过的数字 → 对应下标
```

先查找补数，再记录当前数字，可以防止同一个元素与自己配对。

对应题目：[1. 两数之和](./01-两数之和.py)

### 3. 统一特征分组

如果多个对象具有相同的本质特征，可以把这个特征作为字典的键。

```text
eat → aet
tea → aet
ate → aet
```

```python
symbol = "".join(sorted(word))
```

字典保存：

```text
排序后的统一特征 → 属于这一类的全部字符串
```

对应题目：[49. 字母异位词分组](./49-字母异位词分组.py)

### 4. 频次统计

有时仅知道“出现过”还不够，因为同一个状态可能出现多次，并产生多个答案。这时字典的值应该保存出现次数：

```text
某个状态 → 该状态出现的次数
```

对应题目：

- [560. 和为 K 的子数组](./560-和为k的整数组.py)：统计前缀和出现次数；
- [76. 最小覆盖子串](./76-最小覆盖子串.py)：统计目标字符和窗口字符的数量。

### 5. 集合：只关心“是否存在”

```python
nums_set = set(nums)

if num in nums_set:
    ...
```

集合会去除重复元素，不保存键值对应关系，适合进行成员判断。

#### 只从有效起点扩展

如果从每个数字都向后寻找连续序列，会重复扫描同一段数字。只有满足下面条件的数字才是序列起点：

```python
num - 1 not in nums_set
```

确定起点后，再不断检查 `num + 1` 是否存在。这样每段连续序列只会被完整扩展一次。

对应题目：[128. 最长连续序列](./128-最长连续序列.py)

#### 维护窗口内的元素

集合还可以表示当前窗口中已经存在的字符：

```python
window = set()
window.add(char)
window.remove(char)
```

遇到重复字符时，从窗口左侧不断删除，直到窗口重新满足“没有重复字符”的条件。

对应题目：[3. 无重复字符的最长子串](./03-无重复字符的最长子串.py)

### 字典与集合的选择

| 需求 | 数据结构 | 对应题目 |
| --- | --- | --- |
| 判断元素是否存在 | 集合 | 3、128 |
| 保存元素对应的下标 | 字典 | 1 |
| 按统一特征分类 | 字典，值为列表 | 49 |
| 统计某个状态出现几次 | 字典，值为次数 | 76、560 |

## 二、双指针：利用移动规则排除无效情况

双指针不是某一种固定代码，而是用两个位置共同表示当前状态。关键不在于“定义两个变量”，而在于能否证明每次移动都不会遗漏答案。

思考双指针问题时，需要回答：

1. 两个指针分别表示什么？
2. 当前结果由哪一侧限制？
3. 为什么移动这一侧不会错过更优答案？

### 1. 同向快慢指针：读取与写入分离

`fast` 遍历全部元素，`slow` 指向下一个有效元素应该写入的位置：

```python
slow = 0

for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow] = nums[fast]
        slow += 1
```

处理过程中可以把数组理解为两个区域：

```text
[0, slow)          已经整理好的有效区域
[slow, len(nums))  等待处理或覆盖的区域
```

这种结构也叫原地压缩，适合保留满足条件的元素。

对应题目：[283. 移动零](./283-移动零.py)

### 2. 相向双指针：利用有序性或边界性质

#### 短板原则

容器面积为：

$$
area=\min(height[left],height[right])\times(right-left)
$$

指针向内移动后，宽度一定减小。移动较高的一侧不会改变较矮的限制，还会让宽度变小；只有移动较矮的一侧，才有可能通过增加有效高度得到更大面积。

对应题目：[11. 盛最多水的容器](./11-盛最多水的容器.py)

#### 固定一个数，将三数问题转为两数问题

先排序并固定 `nums[i]`，剩余部分使用左右指针：

```python
left = i + 1
right = len(nums) - 1
```

因为数组有序：

- 当前和太小：右移 `left`；
- 当前和太大：左移 `right`；
- 当前和等于目标：记录答案，同时移动两个指针。

排序还会让重复元素相邻，因此可以分别对固定元素、左指针和右指针去重。

对应题目：[15. 三数之和](./15-三数之和.py)

#### 维护边界状态

单个位置能够接到的雨水由两侧最高柱子的较小值决定：

$$
water_i=\min(left\_max_i,right\_max_i)-height_i
$$

双指针从两端向中间移动，并维护 `left_max` 和 `right_max`。

当 `left_max <= right_max` 时，左侧水量已经能够确定；反之，右侧水量能够确定。每次只处理信息已经充分的一侧。

对应题目：[42. 接雨水](./42-接雨水.py)

### 双指针类型对照

| 类型 | 指针含义 | 移动依据 | 对应题目 |
| --- | --- | --- | --- |
| 同向快慢指针 | 一个读取，一个写入 | 当前元素是否有效 | 283 |
| 相向边界指针 | 表示区间左右边界 | 哪一侧限制当前结果 | 11 |
| 固定元素 + 相向指针 | 固定一项，搜索剩余两项 | 当前和偏大还是偏小 | 15 |
| 相向指针 + 状态维护 | 边界位置与历史最大值 | 哪一侧结果已经确定 | 42 |

## 三、滑动窗口：维护连续区间的状态

滑动窗口本质上也是双指针，但它专门处理字符串或数组中的连续区间：

```text
[left, right]
```

核心不是每次重新计算整个区间，而是在边界移动时增量更新状态：

```text
右侧进入一个元素 → 更新窗口
左侧移出一个元素 → 恢复条件
```

### 1. 变长窗口：寻找满足限制的最长区间

右指针不断扩展窗口。如果新字符造成条件不满足，就移动左指针缩小窗口，直到重新满足条件。

```python
for right in range(len(s)):
    while 当前窗口不满足条件:
        移出 s[left]
        left += 1

    更新最大长度
```

这里通常使用 `while`，因为只移动一次左指针不一定能够让窗口重新满足条件。

对应题目：[3. 无重复字符的最长子串](./03-无重复字符的最长子串.py)

### 2. 定长窗口：每次同时移入和移出

窗口长度始终等于 `len(p)`。窗口移动一格时：

```python
# 左侧字符离开
window_count[ord(s[i]) - ord("a")] -= 1

# 右侧字符进入
window_count[ord(s[i + len(p)]) - ord("a")] += 1
```

两个字符串是字母异位词，不仅要求字符种类相同，还要求每种字符的数量相同。因此不能只比较集合，要比较完整的字符频次。

对应题目：[438. 找到字符串中所有字母异位词](./438-找到字符串中所有字母异位词.py)

### 3. 变长窗口：寻找满足要求的最短区间

第 76 题与第 3 题都使用变长窗口，但目标方向不同：

- 第 3 题：窗口不合法时收缩，合法后记录最大值；
- 第 76 题：窗口合法时持续收缩，并在收缩过程中记录最小值。

第 76 题需要维护两组信息：

```text
dict_goal    目标字符串中每个字符需要的数量
dict_window  当前窗口中这些字符已有的数量
```

还需要使用 `valid` 记录已经满足数量要求的字符种类数：

```text
某个字符的窗口数量刚好达到要求 → valid + 1
移出字符后不再达到要求       → valid - 1
```

只有当：

```python
valid == len(dict_goal)
```

窗口才完整覆盖目标字符串，此时才能尝试移动 `left`，寻找更短的合法窗口。

最终不必在遍历时保存所有子串，只需要记录：

```text
最短窗口的起始位置 + 最短窗口长度
```

遍历完成后再使用切片返回：

```python
s[min_start:min_start + min_length]
```

对应题目：[76. 最小覆盖子串](./76-最小覆盖子串.py)

### 三种窗口对照

| 类型 | 窗口大小 | 左指针移动条件 | 记录目标 | 对应题目 |
| --- | --- | --- | --- | --- |
| 定长窗口 | 始终固定 | 右指针移动时同步移动 | 所有合法起点 | 438 |
| 变长窗口（最长） | 动态变化 | 窗口不满足限制 | 最大长度 | 3 |
| 变长窗口（最短） | 动态变化 | 窗口已经满足要求 | 最小长度和起点 | 76 |

窗口长度的通用公式为：

```python
window_length = right - left + 1
```

如果长度为 $n$ 的字符串中使用长度为 $m$ 的固定窗口，窗口总数为：

$$
n-m+1
$$

## 四、单调队列：快速维护窗口中的最值

普通队列只能保证先进先出，不能直接知道当前窗口中的最大值。第 239 题使用双端队列 `deque` 保存仍有可能成为最大值的元素下标。

### 1. 为什么保存下标，而不是保存数值

保存下标可以同时完成两件事：

- 通过 `nums[index]` 比较元素大小；
- 判断某个元素是否已经离开窗口。

当前窗口左边界为：

```python
window_left = i - k + 1
```

如果队首下标满足：

```python
queue[0] < window_left
```

说明它已经不在当前窗口内，需要从左侧删除。

### 2. 为什么队列保持单调递减

新元素进入时，如果它比队尾对应的元素更大，队尾元素以后不可能再成为窗口最大值：

- 新元素更大；
- 新元素进入得更晚，会更晚离开窗口。

因此可以不断从队尾删除较小元素，使队列中的值按照从大到小排列。

```text
队首                         队尾
当前最大值 → 次大候选 → 更小候选
```

这样，每个完整窗口的最大值始终是：

```python
nums[queue[0]]
```

### 3. 为什么时间复杂度是 O(n)

代码中虽然存在 `while`，但每个下标最多只会：

- 从队尾进入一次；
- 因为失去竞争力或离开窗口而弹出一次。

所有入队和出队操作的总次数与数组长度成正比，所以总时间复杂度仍然是 $O(n)$。

对应题目：[239. 滑动窗口最大值](./239-滑动窗口最大值.py)

## 五、前缀和：把连续区间之和转化为两个状态之差

前缀和表示从数组开头到当前位置的累计和。

如果：

```text
prefix[j] - prefix[i] = k
```

那么：

```text
prefix[i] = prefix[j] - k
```

因此，遍历到当前前缀和 `current_sum` 时，只需要查询此前出现过多少次：

```python
current_need = current_sum - k
```

如果 `current_need` 此前出现了 3 次，就说明存在 3 个以当前位置结尾、和为 `k` 的子数组。

### 为什么初始化 `{0: 1}`

```python
prefix_dict = {0: 1}
```

它表示在遍历数组之前存在一个和为 0 的空前缀。这样当 `current_sum == k` 时，从数组开头到当前位置的子数组也能被正确统计。

### 为什么先查找，再记录当前前缀和

字典中应该只保存当前位置之前的前缀和。尤其当 `k == 0` 时，如果先记录当前前缀和，就可能让当前状态与自己配对，产生不存在的空子数组。

```python
current_need = current_sum - k

if current_need in prefix_dict:
    count += prefix_dict[current_need]

prefix_dict[current_sum] = prefix_dict.get(current_sum, 0) + 1
```

对应题目：[560. 和为 K 的子数组](./560-和为k的整数组.py)

## 六、动态规划：让当前选择复用前面的最优状态

动态规划的核心不是固定模板，而是先确定状态的含义，再寻找状态之间的关系。

第 53 题中，可以把当前状态理解为：

```text
必须以当前位置结尾的最大连续子数组和
```

遍历到一个新元素时，只有两种连续的选择：

1. 接在前面的连续子数组后面；
2. 抛弃前面的部分，从当前元素重新开始。

如果前面的连续和是正数，它会让当前结果变大，应该保留；如果前面的连续和是负数，它只会成为负担，应该从当前元素重新开始。

同时需要区分两个变量：

```text
current_sum  必须以当前元素结尾的最大和
max_sum      遍历过程中出现过的全局最大和
```

### 为什么不能初始化为 0

数组可能全部由负数组成。如果初始化为 0，最终可能得到一个并不存在的空子数组。

因此，状态应该从数组第一个元素开始，这也符合题目中“子数组至少包含一个元素”的要求。

### 状态压缩

如果把每个位置对应的最优状态全部保存到列表中，需要 $O(n)$ 额外空间。但当前状态只依赖前一个状态，因此只保留 `current_sum` 就足够了，额外空间可以压缩为 $O(1)$。

对应题目：[53. 最大子数组和](./53-最大子数组和.py)

## 七、排序的三个作用

排序不只是让数据“看起来整齐”，它还可以改变问题的结构。

### 1. 生成统一特征

字符组成相同的字符串排序后结果相同，可以作为哈希表的分组键。

对应题目：49；438 的初始解法也使用过排序比较窗口。

### 2. 建立单调性

数组有序后，指针向右移动会让数值增大，向左移动会让数值减小，因此能够根据当前和决定移动方向。

对应题目：15。

### 3. 让重复元素相邻

重复元素相邻后，可以使用下面的形式跳过：

```python
while left < right and nums[left] == nums[left - 1]:
    left += 1
```

对应题目：15。

需要同时注意排序成本：

- 排序长度为 $n$ 的列表通常需要 $O(n\log n)$ 时间；
- `sorted(data)` 返回一个新列表；
- `data.sort()` 原地修改列表，并返回 `None`。

## 八、从暴力解法到优化解法

| 暴力方法中的重复工作 | 优化方式 | 对应题目 |
| --- | --- | --- |
| 对每个元素再次遍历寻找搭档 | 用哈希表直接查找补数 | 1 |
| 每次重新检查整个无重复子串 | 用集合维护当前窗口 | 3 |
| 枚举所有左右边界组合 | 根据短板性质排除一侧 | 11 |
| 三重循环寻找三元组 | 排序后固定一项，剩余两项使用双指针 | 15 |
| 对每根柱子重复寻找两侧最高值 | 移动中维护 `left_max` 和 `right_max` | 42 |
| 枚举所有连续子数组并分别求和 | 复用“以当前位置结尾”的最优状态 | 53 |
| 枚举所有起点并重新统计字符 | 在窗口边界移动时增量更新频次 | 76 |
| 从每个数字重复扩展连续序列 | 只从真正的序列起点扩展 | 128 |
| 每个窗口重新扫描寻找最大值 | 用单调队列保留可能成为最大值的下标 | 239 |
| 删除元素后整体移动列表 | 用快慢指针覆盖有效区域 | 283 |
| 每个窗口重新排序或统计 | 只更新移入、移出字符的频次 | 438 |
| 枚举所有连续子数组并求和 | 使用前缀和之差与哈希频次 | 560 |

共同思路是：

> 先找出暴力解法中的重复计算，再思考能否用已有状态、单调关系、移动边界或哈希结构保存它。

## 九、Python 语法与数据结构

### `enumerate()`：同时取得下标和值

```python
for index, value in enumerate(nums):
    ...
```

对应题目：1。

### 字典成员判断与 `get()`

```python
if key in dictionary:
    ...

dictionary[key] = dictionary.get(key, 0) + 1
```

- `key in dictionary` 默认判断键是否存在；
- `get(key, 0)` 表示键不存在时返回默认值 0。

对应题目：1、49、76、560。

### 字典推导式

```python
dict_window = {key: 0 for key in dict_goal}
```

它会遍历 `dict_goal` 中的所有键，并创建一个键相同、初始值都为 0 的新字典。

对应题目：76。

### 集合操作

```python
data = set(nums)
data.add(value)
data.remove(value)
```

- `add()`：添加元素；
- `remove()`：删除元素，元素不存在时会报错；
- `discard()`：删除元素，元素不存在时不会报错；
- 两个集合可以直接使用 `==` 判断包含的元素是否完全相同。

对应题目：3、128。

### `deque`：双端队列

```python
from collections import deque

queue = deque()
queue.append(value)   # 从右侧加入
queue.pop()           # 从右侧删除
queue.popleft()       # 从左侧删除
```

列表的 `pop(0)` 会导致后面的元素整体移动，时间复杂度为 $O(n)$；`deque.popleft()` 可以在 $O(1)$ 时间内从左侧删除。

对应题目：239。

### `sorted()`、`join()` 与字符串切片

```python
chars = sorted("tea")               # ['a', 'e', 't']
word = "".join(chars)                # 'aet'
part = s[left:left + size]           # 截取连续子串
```

对应题目：15、49、76、438。

### `ord()`：把小写字母映射到 0～25

```python
index = ord(char) - ord("a")
```

```text
a → 0
b → 1
...
z → 25
```

对应题目：438。

### 列表相等

```python
list1 == list2
```

只有长度相同且对应位置的元素都相同，两个列表才相等。第 438 题中的两个长度为 26 的计数列表分别保存每个字母的出现次数，因此可以直接比较。

### 条件表达式

```python
return max(lengths) if lengths else 0
```

等价于：

```python
if lengths:
    return max(lengths)
else:
    return 0
```

对应题目：128。
