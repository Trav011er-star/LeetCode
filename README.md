## 一、哈希表与集合

### 1. 两数之和

源码：[01-两数之和.py](./01-两数之和.py)

#### 核心思路

遍历数组时，假设当前数字是 `num1`，需要寻找的另一个数字为：

```python
num2 = target - num1
```

使用字典保存已经遍历过的数字及其下标：

```text
数字 -> 下标
```

如果 `num2` 已经是字典中的键，说明找到了答案；否则将当前数字与下标加入字典。

```python
nums_set = {}

for i, num1 in enumerate(nums):
    num2 = target - num1

    if num2 in nums_set:
        return [nums_set[num2], i]

    nums_set[num1] = i
```

#### 关键知识点

- `enumerate(nums)` 可以同时获得元素的下标和值。
- `dictionary[key] = value` 可以添加或修改键值对。
- 对字典使用 `in`，默认判断对象是否存在于字典的键中。
- 必须先查找再保存，防止同一个元素与自己配对。

#### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

### 49. 字母异位词分组

源码：[49-字母异位词分组.py](./49-字母异位词分组.py)

#### 核心思路

字母异位词中的字符及其出现次数相同，只是排列顺序不同。把字符串中的字符排序后，同一组字符串会得到相同的结果：

```text
eat -> aet
tea -> aet
ate -> aet
```

因此，可以把排序后的字符串作为字典的键，把原字符串保存到对应的列表中：

```text
排序结果 -> 原字符串列表
```

```python
symbol = "".join(sorted(word))

if symbol in c_dict:
    c_dict[symbol].append(word)
else:
    c_dict[symbol] = [word]
```

#### 关键知识点

- `sorted(word)` 对字符排序并返回字符列表。
- `"".join(...)` 将字符列表重新连接成字符串。
- 字典的键负责表示分类特征，值使用列表保存属于该类别的全部元素。
- `append()` 向列表末尾添加一个元素。
- 遍历字典时默认遍历键，可以通过键取得对应的值。

#### 复杂度

假设共有 $n$ 个字符串，每个字符串的最大长度为 $k$：

- 时间复杂度：$O(nk\log k)$
- 空间复杂度：$O(nk)$

### 128. 最长连续序列

源码：[128-最长连续序列.py](./128-最长连续序列.py)

#### 核心思路

首先把数组转换成集合：

```python
nums_set = set(nums)
```

集合可以去除重复元素，并支持平均 $O(1)$ 的成员查找。

对于当前数字 `num`，只有当 `num - 1` 不在集合中时，`num` 才可能是一段连续序列的起点：

```python
if num - 1 in nums_set:
    continue
```

找到起点以后，再不断判断后一个数字是否存在：

```python
current_len = 1
num += 1

while num in nums_set:
    num += 1
    current_len += 1
```

#### 为什么是线性复杂度

如果从每个数字都向后查找，会重复遍历同一段序列。当前代码只从序列起点开始查找，因此一段序列中的每个数字只会在扩展过程中被访问一次，整体时间复杂度为 $O(n)$。

#### 关键知识点

- `set(nums)` 将列表转换成集合并去重。
- 集合适合处理“某个元素是否存在”的问题。
- 先识别序列起点，可以避免重复搜索。
- Python 没有直接的 `do...while`，可以使用普通 `while` 组织循环。
- 空数组需要单独处理，当前代码使用条件表达式返回 `0`。

#### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

## 二、双指针

双指针不是 Python 中特殊的数据类型，而是使用两个变量记录两个位置。其核心是根据当前状态决定移动哪一个指针，从而排除一批不可能的情况，减少重复遍历。

本仓库目前使用了四种双指针形式：

| 题目 | 双指针形式 | 指针含义 | 移动依据 |
| --- | --- | --- | --- |
| 移动零 | 同向快慢指针 | `fast` 负责寻找，`slow` 负责写入 | 找到非零元素就写入有效区域 |
| 盛最多水的容器 | 相向双指针 | 两个指针表示容器的左右边界 | 移动当前较矮的柱子 |
| 三数之和 | 固定一个数 + 相向双指针 | `p1`、`p2` 寻找另外两个数 | 根据当前三数之和增大或减小 |
| 接雨水 | 相向双指针 + 状态维护 | 维护左右已知的最高柱子 | 处理 `left_max`、`right_max` 中较小的一侧 |

双指针真正重要的问题不是“设置两个变量”，而是：

1. 两个指针分别表示什么？
2. 当前状态能够确定哪一侧的结果？
3. 为什么移动这个指针不会遗漏答案？

### 283. 移动零

源码：[283-移动零.py](./283-移动零.py)

#### 核心思路

使用同向快慢指针：

- `fast` 遍历整个数组，寻找非零元素；
- `slow` 指向下一个非零元素应该写入的位置。

```python
slow = 0

for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow] = nums[fast]
        slow += 1
```

完成第一次遍历后，`nums[0:slow]` 已经保存了全部非零元素，再将后面的元素统一设置为 `0`：

```python
for i in range(slow, len(nums)):
    nums[i] = 0
```

#### 指针含义

```text
fast：读取指针，负责检查每个元素
slow：写入指针，负责维护有效区域
```

这种“读取位置 + 写入位置”的结构也称为原地压缩，适合删除、移动或保留满足条件的元素。

#### 关键知识点

- 列表是可变对象，可以通过下标原地修改。
- `nums[slow] = nums[fast]` 是覆盖元素，而不是插入元素。
- LeetCode 要求原地修改数组，当前代码最后的 `return nums` 不影响结果，但不是必需的。

#### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

### 11. 盛最多水的容器

源码：[11-盛最多水的容器.py](./11-盛最多水的容器.py)

#### 核心公式

两个柱子构成的容器面积为：

```python
area = min(height[left], height[right]) * (right - left)
```

其中：

- 宽度由两个下标的距离决定；
- 高度由较矮的柱子决定。

#### 为什么移动较矮的一边

两个指针向中间移动后，宽度一定减小。如果移动较高的一边，较矮的柱子仍然限制容器高度，面积不可能变大。

只有移动较矮的一边，才有机会遇到更高的柱子，用高度增加弥补宽度减小。因此每轮计算面积后，移动当前较矮的一侧。

```python
if height[left] < height[right]:
    left += 1
else:
    right -= 1
```

#### 复杂度

- 时间复杂度：$O(n)$
- 当前代码空间复杂度：$O(n)$，因为使用列表保存了每次计算的面积
- 如果只保存最大面积，空间复杂度可以降为 $O(1)$

### 15. 三数之和

源码：[15-三数之和.py](./15-三数之和.py)

#### 核心思路

先排序数组，然后固定第一个数字 `nums[i]`，再使用相向双指针寻找另外两个数字：

```python
p1 = i + 1
p2 = len(nums) - 1
```

计算三数之和：

```python
current_sum = nums[i] + nums[p1] + nums[p2]
```

因为数组已经有序：

- `current_sum < 0`：和太小，右移 `p1`，让结果增大；
- `current_sum > 0`：和太大，左移 `p2`，让结果减小；
- `current_sum == 0`：记录答案，并同时移动两个指针。

#### 去重规则

本题不仅需要找到答案，还要避免重复三元组，因此需要在三个位置去重：

1. 固定数字 `nums[i]` 与前一个固定数字相同时，跳过当前循环；
2. 移动 `p1` 后跳过连续的相同元素；
3. 移动 `p2` 后跳过连续的相同元素。

排序不仅让双指针能够根据和的大小确定移动方向，也让重复元素相邻，从而方便去重。

#### 提前结束

数组排序后，如果：

```python
nums[i] > 0
```

那么后面的数字都大于或等于 `nums[i]`，三数之和不可能等于 `0`，可以直接结束循环。

#### 复杂度

- 排序：$O(n\log n)$
- 固定元素与双指针：$O(n^2)$
- 总时间复杂度：$O(n^2)$
- 额外空间复杂度：$O(n)$，不包含返回结果

### 42. 接雨水

源码：[42-接雨水.py](./42-接雨水.py)

#### 从整片水池转换成单根柱子

这道题不容易直接按照一整块水池计算。更清晰的方法是计算每根柱子上方能够保存多少水。

对于位置 `i`：

```text
当前位置水量 = min(左边最高柱子, 右边最高柱子) - 当前柱子高度
```

写成公式：

$$
water_i = \min(left\_max_i, right\_max_i) - height_i
$$

#### 双指针优化

暴力方法需要对每根柱子分别向左、向右寻找最高值，时间复杂度为 $O(n^2)$。双指针在移动过程中维护：

```python
left_max = height[left]
right_max = height[right]
```

如果：

```python
left_max <= right_max
```

说明右边已经存在一面不低于 `left_max` 的墙。左侧水面一定由较小的 `left_max` 决定，因此可以处理左侧并移动 `left`。

反之，右侧水面由 `right_max` 决定，可以处理右侧并移动 `right`。

```python
while left < right:
    if left_max > right_max:
        right -= 1
        right_max = max(right_max, height[right])
        pool_volume += right_max - height[right]
    else:
        left += 1
        left_max = max(left_max, height[left])
        pool_volume += left_max - height[left]
```

#### 与盛最多水的容器的区别

两道题都从两端开始并处理较矮的一侧，但判断依据不同：

| 题目 | 比较内容 | 原因 |
| --- | --- | --- |
| 盛最多水的容器 | 当前两根柱子的高度 | 当前容器高度由较矮柱子限制 |
| 接雨水 | 左右两侧已经遇到的最高值 | 单根柱子的水面由左右最高边界中较小者决定 |

#### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

## Python 语法与数据结构总结

### 字典

```python
num_index = {}
num_index[num] = index
```

适合保存“对象到信息”的映射，例如：

```text
数字 -> 下标
分类标志 -> 同类元素列表
```

### 集合

```python
nums_set = set(nums)
```

适合去重和快速判断元素是否存在，但不保存键值对应关系。

### `enumerate()`

```python
for i, num in enumerate(nums):
```

遍历序列时，同时得到下标 `i` 和元素 `num`。

### `sorted()` 与 `.sort()`

```python
new_nums = sorted(nums)
nums.sort()
```

- `sorted(nums)` 返回一个新的有序列表；
- `nums.sort()` 直接修改原列表，返回值为 `None`。

### `join()`

```python
symbol = "".join(["a", "e", "t"])
```

使用空字符串连接字符，结果为 `"aet"`。

### 条件表达式

```python
return max(lens) if len(lens) > 0 else 0
```

等价于：

```python
if len(lens) > 0:
    return max(lens)
else:
    return 0
```
